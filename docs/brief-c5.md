## 1. Metadata (draft 14)

Add `lib/metadata.ts` with one helper used by every page:

```ts
pageMetadata({ title, description, path, type? }): Metadata
// returns title, description,
// alternates.canonical = path,
// openGraph { title, description, url: path, type: type ?? "website", siteName: "Ben Sproat", locale: "en_US" },
// twitter { card: "summary_large_image", title, description }
```

Reason: Next merges `openGraph` shallowly, so a page that sets its own title must also set its own `openGraph` block, or the card shows the site default. One helper keeps every page consistent.

- Root layout: `metadataBase` stays; default `openGraph` and `twitter` as above for `/`.
- Every route uses the helper with its existing title and description (home: `title` "Ben Sproat", description = `profile.headline`). Project pages pass `type: "article"`.
- `/links`: `robots: { index: false, follow: true }` (it duplicates the other pages and is the NFC landing, not a search page). 404 stays unindexed (Next default).
- Descriptions between 70 and 160 characters. If a page's description is outside that range, list it in the PR instead of rewriting copy.
